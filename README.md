# 🧪 LabInsight AI

### Multi-Agent Medical Laboratory Report Analysis System

LabInsight AI is an **AI-powered medical laboratory report analysis prototype** built using **LangGraph, RAG, Sentence Transformers, FAISS, Groq LLMs, and Streamlit**.

The system processes a laboratory report through a multi-agent pipeline to extract report information, retrieve relevant medical knowledge, interpret findings, assign an attention priority, validate the generated information, and present the result in a user-friendly format.

> ⚠️ **Medical Disclaimer:** This project is an educational prototype and is not intended to diagnose medical conditions, prescribe medication, or replace professional medical advice.

---

* 📄 Laboratory report information extraction

## 🤖 Multi-Agent Pipeline

### Agent 1 — Report Extraction

Extracts structured information from the laboratory report.

Current extracted fields include:

* Test name
* Result value
* Unit
* Reference range
* Extracted report data

The agent is instructed to use only information present in the supplied report.

---

### Agent 2 — RAG Interpretation

Agent 2 combines the extracted laboratory information with relevant knowledge retrieved from a medical knowledge base.

The RAG pipeline uses:

```text
Medical Knowledge
      ↓
Text Chunking
      ↓
Sentence Transformers
      ↓
Embeddings
      ↓
FAISS
      ↓
Relevant Chunks
      ↓
LLM Interpretation
```

The retrieved information is used to generate an educational interpretation of the laboratory finding.

---

### Agent 3 — Attention Priority

Agent 3 analyzes the interpreted finding and generates an attention priority such as:

```text
HIGH
MEDIUM
LOW
```

The priority is intended as an **attention indicator generated by the system**, not a clinical diagnosis or medical risk score.

---

### Agent 4 — Validation

Agent 4 performs a consistency check between the extracted report information and the prioritized finding.

It checks:

* Whether required information is present
* Whether the generated finding is consistent with the extracted report
* Whether any fields are missing

---

### Agent 5 — Final Response

Agent 5 converts the processed information into a user-friendly response containing:

* Summary
* Explanation
* Attention priority
* Suggested next steps
* Missing information
* Medical disclaimer

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/JOEL-ZERUBABEL/LabInsight-AI.git
```

```bash
cd LabInsight-AI
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

#### Windows

```powershell
.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the project directory:

```env
GROQ_API_KEY=your_groq_api_key
```

The `.env` file should **not** be committed to GitHub.

The repository includes `.gitignore` to prevent the API key from being uploaded.

---

## ▶️ Running the Application

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

You can then:

1. Upload a laboratory report `.txt` file
2. Or paste the report into the text area
3. Click **Analyze Report**
4. View the final analysis
5. Expand the agent sections to inspect the processing pipeline

* Validation between agents
* Human-readable AI responses
